# Как добавить новый объект

1. Положить исходные фото (любого разрешения, хоть 6000 px) в `img/<slug>/`
   с именами `00.jpg`, `01.jpg`, … — по одному файлу на кадр.
   Отдельные превью делать **не нужно**, они генерируются сами.

2. Прогнать оптимизацию:

   ```bash
   python tools/optimize-images.py
   python tools/build-img-sizes.py
   ```

   Первый скрипт из каждого `NN.jpg` собирает набор:

   | файл | ширина | для чего |
   |---|---|---|
   | `NN.webp` | 1600 px | лайтбокс |
   | `NN-1100.webp` | 1100 px | карточка на retina и планшете |
   | `NN-640.webp` | 640 px | карточка 1x и смартфон |
   | `NN.jpg` | 1200 px | запасной вариант для браузеров без WebP |

   Кадры в `img/hotel-lobby/` дополнительно получают `NN-2200.webp` —
   они работают фоном на весь экран в шапке сайта.

   Второй скрипт пересобирает `img-sizes.js` — карту размеров, по которой
   `app.js` строит `srcset`. **Без этого шага новые фото не появятся.**

3. Добавить запись об объекте в `data.js` (`slug`, `title`, `shots` и т. д.).

## Важно

Скрипт **перезаписывает** `NN.jpg` сжатой версией. Оригиналы в максимальном
разрешении лежат в `extracted_rar/` и не попадают в репозиторий — держите их
там или в другом надёжном месте.

Повторный прогон по уже сжатым файлам ухудшит качество: каждый проход
JPEG теряет детали. Запускайте оптимизацию один раз на новую партию фото.

## Требования

Python 3 и Pillow:

```bash
pip install Pillow
```
